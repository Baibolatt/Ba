# Тестовые прайс-листы

Файлы создаются скриптом `npm run generate:samples` и проверяются командой
`npm run test:import` на временной базе SQLite.

| Файл | Что проверяет |
| --- | --- |
| `clean-russian.xlsx` | Русские заголовки, цены с пробелами, остатки `>10`, «есть», «нет», невидимый символ в артикуле |
| `english-company-header.xlsx` | Английские заголовки, шапка компании сверху, пустые строки, два листа, `$` с курсом и наценкой |
| `chinese-headers.xlsx` | Китайские заголовки, `¥` с курсом, остатки «有货» / «无货» |
| `dirty-windows1251.csv` | Windows-1251, разделитель `;`, «12 500 тг», `1 234,50`, `2.500`, кавычки, дубликат артикула, ошибка цены |

Ожидаемые результаты подробно зафиксированы в `scripts/test-import.ts`:
количество добавленных и обновлённых товаров, строки с ошибками, дубликаты,
пересчитанные цены и остатки.
