# Карта типов страниц PartsHub (этап 2)

Референс: `https://autodoc.ru` — только структура, раскладка и паттерны взаимодействия.
Бренд, палитра, тексты, логотип, фотографии и названия брендов — свои.

## Как снималась карта

| Источник | Что дал |
| --- | --- |
| `https://www.autodoc.ru/` | общая оболочка: шапка, поиск, каталог, корзина, кабинет |
| `robots.txt` | список публичных и закрытых разделов (`/cart`, `/Account/*`, `/price/*`, `/company/*`) |
| `sitemap/ru/sitemap.xml` | структура каталога: категории автомобилей и товаров |
| публичная структура разделов | «Клиентам», «Компания», «Обратная связь», вход/регистрация, кабинет |

**Ограничение.** Сайт — клиентское SPA: все маршруты отдают одинаковую HTML-оболочку
(49 658 байт, `<title>Автодок</title>`) без отрендеренного контента. Браузера в окружении
нет, папка `design-references/` отсутствует, поэтому пиксельные скриншоты снять не удалось.
Раскладка восстановлена по публичной структуре маршрутов и типовым паттернам мобильного
каталога автозапчастей. Повторные обходы сайта не выполнялись.

## Раскладка и токены

| Параметр | Значение |
| --- | --- |
| Базовая сетка | 4px, основные шаги 8 / 12 / 16 / 24 / 32 / 40 |
| Максимальная ширина | 1200px |
| Отступ контента | 16px mobile, 24px tablet, 32px desktop |
| Карточки товаров | 2 колонки mobile, 3 tablet, 4 desktop, gap 12/16 |
| Радиусы | 10px — контролы, 14px — карточки, 20px — листы, 999px — пилюли |
| Типографика | 12 / 14 / 16 / 18 / 20 / 24 / 30 / 36; веса 400 / 500 / 600 / 700 |
| Шрифт | системный sans (без загрузки внешних шрифтов) |
| Шапка | 56 + 48px mobile, 72px desktop |
| Нижняя навигация | 64px + safe-area |
| Тени | карточка — мягкая, лист/меню — крупная |
| Движение | 150–200ms, `ease-out` |

не для мелкого текста на белом (низкий контраст); на оранжевой кнопке текст тёмно-синий.

## Тестовые данные

`src/lib/mock-data.ts`: 6 категорий, 12 товаров. У товара: `id`, `name`, `brand`
(вымышленные: ТехноЛайн, АвтоЭра, МоторКрафт, ГрандФильтр, ОйлПро, СевероПартс),
`article`, `categorySlug`, `price`, `oldPrice?`, `stock`, `unit`, `description`, `specs`.
Заказы, уведомления и адреса — отдельные константы в том же файле.
