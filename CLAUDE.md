# CLAUDE.md

## Язык общения

- Отвечай пользователю **только на русском языке** — во всех ответах, пояснениях и вопросах.
- Код, имена переменных и функций, команды, пути к файлам и содержимое файлов не переводить.

## Работа с репозиторием

- Перед изменениями проверяй текущее состояние через `git status` и `git diff`.
- Не коммить и не пушь изменения без явной просьбы пользователя.
- Сохраняй существующий стиль кода и форматирование файлов.

## Документация

- README.md — описание проекта и инструкция по запуску.
- При изменении поведения проекта обновляй README.md.
