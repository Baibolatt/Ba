# PartsHub

Дизайн-макет сайта оптового склада автозапчастей. Проект сделан на тестовых
данных: база данных, авторизация и оплата на этом этапе не подключены, все
интерактивные сценарии работают в браузере.

## Стек

- Next.js 16 (App Router) и React 19
- TypeScript в строгом режиме
- Tailwind CSS v4, дизайн-токены в `src/app/globals.css`
- Внешних UI-библиотек нет: иконки, компоненты и заглушки изображений свои

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:3012](http://localhost:3012).

Сборка и запуск production-версии:

```bash
npm run build
npm start
```

## Структура

```
src/
  app/                 маршруты App Router
  components/
    account/           кабинет: навигация, заказы, профиль, избранное
    cart/              корзина и итоговая панель
    catalog/           карточки, таблица, фильтры, подбор авто
    checkout/          оформление заказа
    feedback/          форма обратной связи
    layout/            шапка, подвал, боковое меню, нижняя навигация
    providers/         корзина, избранное и уведомления в React-контексте
    ui/                кнопки, поля, значки, аккордеон, хлебные крошки
  lib/
    mock-data.ts       тестовые категории, товары, заказы, уведомления
    cn.ts              объединение классов
docs/
  PLAN.md              план этапов проекта
  research/site-map.md карта типов страниц и принятые решения
```

## Маршруты

| Маршрут | Назначение |
| --- | --- |
| `/` | Главная: подбор авто, категории, хиты склада |
| `/catalog` | Каталог: все категории |
| `/catalog/[slug]` | Товары категории, фильтры, сортировка, карточки/таблица |
| `/product/[id]` | Страница товара, характеристики, похожие позиции |
| `/search?q=...` | Результаты поиска |
| `/cart` | Корзина |
| `/checkout` | Оформление заказа в три шага |
| `/checkout/success` | Подтверждение заказа |
| `/login`, `/register` | Вход и регистрация |
| `/account` | Личный кабинет |
| `/account/profile` | Профиль |
| `/account/orders`, `/account/orders/[id]` | Заказы и детали заказа |
| `/account/favorites` | Избранное |
| `/account/notifications` | Уведомления |
| `/for-customers` | Доставка, оплата, возврат, вопросы и ответы |
| `/company` | О компании, реквизиты, контакты |
| `/feedback` | Форма обратной связи |

## Тестовые данные

- 6 категорий и 12 товаров с вымышленными брендами
- Фотографии заменены SVG-заглушками по категориям
- Профиль, три заказа и четыре уведомления в `src/lib/mock-data.ts`
- Корзина и избранное хранятся в React-контексте и сбрасываются при
  перезагрузке страницы

## Оформление

- Бренд: тёмно-синий `#14213D`, акцент: оранжевый `#F28C28`
- Зелёный используется только для статуса наличия товара
- Все цвета, радиусы и тени заданы токенами в `src/app/globals.css`
- Мобильная версия рассчитана на ширину 390px, десктоп — контейнер 1200px

## Ограничения этапа

Отзывы и оценки, подбор по VIN, баланс, онлайн-оплата, загрузка фото,
карта пунктов выдачи и чат поддержки не реализованы — подробнее в
`docs/research/site-map.md`.
