# PartsHub

Демонстрационный сайт оптового склада автозапчастей. Каталог, категории, товары,
заказы и поиск читаются из SQLite через Prisma. Корзина, избранное и оформление
заказа пока работают в браузере: новый заказ из формы не сохраняется в базе,
авторизация и оплата не подключены.

## Стек

- Next.js 16 (App Router) и React 19
- TypeScript в строгом режиме
- Tailwind CSS v4, дизайн-токены в `src/app/globals.css`
- Prisma 7, SQLite и драйвер `better-sqlite3`
- Внешних UI-библиотек нет: иконки, компоненты и заглушки изображений свои

## Запуск

```bash
npm install
npm run db:setup
npm run dev
```

`npm run db:setup` — одна команда, которая поднимает базу с нуля: применяет
миграции, создаёт `prisma/dev.db` и запускает seed с тестовыми данными.
Повторный запуск пересоздаёт демо-данные. Если файла `.env` нет, используется
путь по умолчанию `file:./prisma/dev.db`; пример переменной — в `.env.example`.

Сайт откроется на [http://localhost:3012](http://localhost:3012).

Дополнительные команды:

```bash
npm run db:migrate   # новая миграция после изменения schema.prisma
npm run db:seed      # только тестовые данные
npm run db:studio    # Prisma Studio
```

Сборка и запуск production-версии:

```bash
npm run build
npm start
```

При сборке страницы читают данные из базы, поэтому сначала выполните
`npm run db:setup`.

## База данных

- `Category` и `Brand` — отдельные таблицы, у товара внешние ключи на бренд и
  категорию
- `Product`: уникальный артикул, название, цена в тенге целым числом, остаток
  `quantity`, фото `imageUrl`, описание и совместимость с авто текстом
- `inStock` не хранится в базе — вычисляется в `src/lib/data.ts` как
  `quantity > 0`
- Индексы: уникальный по `Product.article` и обычный по `Product.name` для
  будущего быстрого поиска
- `Order` и `OrderItem`: имя, телефон, адрес или самовывоз, комментарий, статус
  (`new`, `in_progress`, `done`), дата; позиции хранят количество и цену на
  момент заказа
- Файл `prisma/dev.db` и его служебные файлы в `.gitignore`; в репозитории
  лежат только схема, миграции и seed

## Тестовые данные

- 6 категорий, 6 брендов и 12 товаров с вымышленными брендами
- Три заказа с разными статусами и позициями
- Цены в тенге, формат — через `formatPrice()`: `12 500 ₸`
- Склад и доставка — Тараз и Жамбылская область, доставка без расчёта стоимости
- Фотографии заменены заглушками по иконке категории
- Профиль и четыре уведомления остаются демо-данными в `src/lib/mock-data.ts`
- Корзина и избранное хранятся в React-контексте и сбрасываются при
  перезагрузке страницы

## Оформление и адаптивность

- Один акцент — синий `#1D4ED8`; фон страниц светло-серый, карточки белые,
  текст — нейтральный тёмно-серый
- Акцент используется для главных кнопок, цен и активных элементов; зелёный и
  красный — только для статуса наличия товара
- Все цвета, радиусы и тени заданы токенами в `src/app/globals.css`
- Мобильная версия (360–430px): компактная шапка с бургер-меню и поиском,
  карточки в 2 колонки, фиксированная нижняя навигация, без горизонтального
  скролла страницы
- Десктоп (от 1024px): шапка в одну строку, контейнер 1280px, 4 карточки в ряд,
  фильтры левой колонкой, страница товара в две колонки

## Ограничения этапа

Оформление заказа пока не записывает `Order` в базу, отзывы и оценки, подбор по
VIN, баланс, онлайн-оплата, загрузка фото, карта пунктов выдачи и чат поддержки
не реализованы — подробнее в `docs/research/site-map.md`.
